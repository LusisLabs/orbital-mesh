Stop rule If the same error occurs twice, stop patching randomly. Research 3-5 plausible fixes, choose the smallest correct fix for this repo, implement it, and document the choice.

Morning Handoff Format

The overnight run is only useful if the next operator can trust what happened.

Required final report

  • Changed state slices.
  • web/ to meshapp/ parity inventory with port, reuse, replace, and deprecate classifications.
  • Files changed, grouped by owner.
  • Validation command results with exact pass/fail status.
  • Browser smoke scenarios and screenshots.
  • Blocked provider credentials or environment requirements.
  • Remaining risks and non-claims.

Non-negotiable boundaries

  • Use pnpm, not npm.
  • Do not run tail.
  • Preserve unrelated dirty worktree changes.
  • Every mutation names its state slice before editing.
  • Keep Mesh as authority for policy, approvals, readiness, evidence, run state, and actuation.
