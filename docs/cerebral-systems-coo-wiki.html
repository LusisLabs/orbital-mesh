Design-Partner Pilot Motion

90-day pilot definition

Sell a controlled remediation pilot, not a broad autonomy platform. The first pilot should prove one allowed action, one denied action, operator approval, rollback metadata, live feedback, and a reviewable run export inside a customer-controlled environment.

Pricing hypothesis

Pick one fixed number. Do not leave the pilot price fuzzy when talking to buyers.

$15k pilot $25k pilot $30k pilot

Credit toward annual contract only if the pilot converts.

Team Handoff

Message to team

Cerebral Systems is being organized as the legal and operating parent for the product work. This weekend priority is not brand polish. It is company hygiene: formation records, EIN, bank readiness, cap table, IP ownership, compliance calendar, first pilot package, security packet, and a proof-driven claim boundary.

The commercial motion starts with controlled remediation pilots. We are not selling broad autonomous production control. We are selling a bounded, policy-guided, operator-steerable remediation control plane with evidence, approval, audit trail, and run export.

Each team member should own a concrete surface: corporate docs, finance stack, IP cleanup, product proof, security packet, pilot pipeline, or customer collateral. No loose claims, no unowned documents, no undocumented commitments.

Refresh rules

Before filing, fundraising, issuing securities, making tax elections, or relying on state compliance status, refresh the official source and use counsel or tax support. BOI status, state requirements, and filing fees are drift-prone.

This wiki is an operating checklist, not legal, tax, or securities advice.
